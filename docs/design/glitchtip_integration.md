# GlitchTip Integration Design

## The "Why"
**Бизнес-проблема**: Приложение не отправляет структурированные сообщения об ошибках. Необходимо централизованное логирование и оповещение об exceptions через облачный сервис GlitchTip (https://app.glitchtip.com/).
**Отброшенные альтернативы**:
- Использование стандартного `logging` без внешнего сервиса — отклонено, так как не предоставляет удобного UI для аналитики инцидентов и оповещений.
- Собственная реализация отправки запросов в API GlitchTip — отклонено (KISS), так как существует готовый, поддерживаемый и протестированный `sentry-sdk`.

## Minimal Data Model
- Секретный ключ (DSN): Хранится в файле конфигурации `.streamlit/secrets.toml`.
- Структура конфигурации секретов:
```toml
[glitchtip_settings]
DSN = "https://..."
```

## API Contracts
- Использование стандартного пакета `sentry-sdk` (совместимого с GlitchTip).
- При старте `app.py` происходит чтение `st.secrets.get("glitchtip_settings", {}).get("DSN")`.
- Если DSN задан, вызывается `sentry_sdk.init(dsn=...)`.
- Все необработанные исключения автоматически перехватываются SDK и отправляются в GlitchTip.
