### PROJECT AI DEVELOPER PREFERENCES
*Этот файл содержит индивидуальные настройки и инструкции для текущего проекта.*

#### О проекте
**reconciliation-project** — сервис автоматической сверки документов (спецификаций, заявок) с использованием LLM.

#### Стек технологий
*   **Язык**: Python >= 3.11
*   **Пакетный менеджер**: `uv` (зависимости описаны в `pyproject.toml`, зафиксированы в `uv.lock`)
*   **UI**: Streamlit
*   **LLM/Структурирование**: `instructor`, `pydantic`, SDK от провайдеров (`google-genai`, `openai`, `anthropic`)
*   **Линтинг и форматирование**: `ruff`
*   **Тестирование**: `pytest`

#### 1. Управление зависимостями (Python & uv)
*   **Пакетный менеджер:** В проекте строго используется **uv**.
*   **Запрет на альтернативы:** Категорически запрещено использовать `pip`, `poetry` или `pipenv` для управления пакетами или окружением.
*   **Операции с зависимостями:**
    *   **Добавление:** Используй `uv add <package_name>`.
    *   **Синхронизация:** Используй `uv sync` для приведения окружения в соответствие с lock-файлом.
    *   **Обновление:** Используй `uv lock` для обновления зависимостей.
*   **Запуск:** Для выполнения скриптов или инструментов используй `uv run <command>` или `uvx <tool>` для временных окружений.
*   **Виртуальное окружение:** Всегда используй интерпретатор из локальной папки `.venv`, созданной через `uv`. Все команды должны выполняться через него (например, `.venv/bin/python`, `.venv/bin/pytest`).

#### 4. Специфические правила проекта
*   **Simplicity:** Если задачу можно решить через стандартную библиотеку Python (pathlib, json, dataclasses), не добавляй внешние зависимости через `uv`.
*   **Секреты**: Настройки LLM и API-ключи берутся из секретов Streamlit (`st.secrets`).
